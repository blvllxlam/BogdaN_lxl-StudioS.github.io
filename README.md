# Bogdan Portfolio

A responsive portfolio website built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Before publishing
Open `script.js` and replace:
- `YOUR_EMAIL@example.com`
- `YOUR_TELEGRAM`

## Free hosting
This site can be hosted for free on GitHub Pages or Cloudflare Pages.
No server or paid hosting is required.

## Main files
- `index.html` — page structure/content
- `style.css` — design/responsive layout
- `script.js` — navigation, animations and project modal
